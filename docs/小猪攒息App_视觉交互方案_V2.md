**小猪攒息 App 视觉交互方案**

基于确定视觉：A8 陪伴感 + A9 清爽背景 + A11 资产双页结构

版本：V2.0 \| 方向：A8布局 + A9清爽背景 + 小猪攒息资产体系 \| 日期：2026-07-01

# 1. 最终视觉方向

最终方向采用“小猪攒息清爽陪伴风”：整体像一个小猪存钱罐，而不是股票分析 App。A8 的布局、小猪资产陪伴感和资产卡片风格保留；A9 的干净背景、轻量留白和舒适感作为整体底色；A11 的“我的资产 / 关注资产”结构进入正式方案。

| **视觉关键词** | **解释**                           | **落地方式**                                 |
|----------------|------------------------------------|----------------------------------------------|
| 小猪存钱罐     | 强认知、低门槛、天然对应“慢慢攒钱” | 首页大猪、资产小猪、弹窗小猪、目标小猪贯穿。 |
| 攒息陪伴       | 不是冷冰冰数据，而是每天一点点进账 | 账本、日历、目标里都用温暖文案和小猪反馈。   |
| 清爽背景       | 减少旧版纸感噪声，保留暖白舒适感   | 大面积暖白/奶油底，少纹理，卡片轻阴影。      |
| 红色分红       | 红色从涨跌中剥离，只用于收钱与分红 | 所有分红金额、到账金额、目标关键数字用红。   |
| 去股票化       | 隐藏 K 线、涨跌、盘口等专业符号    | 页面优先展示已攒、待入账、目标、账本。       |

# 4. 插画与小猪资产体系

小猪是产品的核心识别资产。不同页面的小猪承担不同情绪功能，不同资产的小猪承担“打钱伙伴”的角色。

| **小猪类型** | **使用场景**      | **设计要点**                                                   |
|--------------|-------------------|----------------------------------------------------------------|
| 首页大猪     | 首页主视觉        | 圆润、可爱、稳定，旁边有小牌子“慢慢攒 自由来”。                |
| 入账小猪     | 再次打开弹窗      | 拿金币、撒花、开心，强化“又有钱进罐”的即时反馈。               |
| 账本小猪     | 分红账本          | 趴在账本/金币旁，像在帮用户记录每一笔到账。                    |
| 日历小猪     | 攒息日历          | 小尺寸图标，用于月度汇总卡和关键日期。                         |
| 退休小猪     | 退休目标          | 坐在椅子上、喝茶、看书，表达退休后的从容。                     |
| 资产小猪     | 我的资产/关注资产 | 每个资产一个特殊小猪形象，如运营商猪、电力猪、海油猪、农业猪。 |

# 6. 页面视觉与交互规范

## 6.1 首页 / 今天又攒了多少

**•** 首屏结构：标题 → 今年已攒红色大数字 → 小猪主视觉 → 退休目标进度 → 本月分红与分红笔数 → 鼓励文案。

**•** 首页不要出现股价、涨跌、K线、资产市值。

**•** 小猪罐随攒息进度可做轻微成长，如金币变多、小猪表情更开心、背景小牌子变化。

**•** “距离退休目标还差”要比“总资产”更靠前，强化目标感而不是财富焦虑。

## 6.2 再次打开弹窗

| **元素** | **规范**                                              |
|----------|-------------------------------------------------------|
| 弹窗背景 | 页面背景轻微暗化，不要完全黑，保持温暖。              |
| 主标题   | 欢迎回来 / 这几天你又攒到钱啦。                       |
| 主数字   | 新增到账金额，大号红色，视觉最强。                    |
| 辅助信息 | 本月累计已攒、还有多少在路上。                        |
| 插画     | 小猪抱金币或两只小猪一起存钱，轻微彩屑即可。          |
| 按钮     | 主按钮红色：“去看看小猪罐/查看账本”；次按钮灰色弱化。 |

## 6.3 分红账本

**•** 账本风格要像收入流水，但比银行流水更温暖。

**•** 使用“全部 / 已到账 / 待到账”分段控件，已到账默认优先。

**•** 每条记录使用资产 Logo + 名称 + 日期 + 红色金额，信息不要超过两行。

**•** 待到账分组放在已到账下方，用浅红底或浅灰底提示“预计”。

## 6.4 攒息日历

| **组件**   | **视觉/交互要求**                                                |
|------------|------------------------------------------------------------------|
| 月份切换   | 顶部左右箭头，月份居中；保持简洁。                               |
| 日期标记   | 已到账：实心红点；待到账：浅红描边；多笔：小红点叠加或数字角标。 |
| 月度汇总卡 | 本月已收到、本月还会收到两张并列卡，金额红色。                   |
| 近期待到账 | 最多展示 3 条，查看更多进入账本。                                |
| 日期弹层   | 点击日期弹出当天记录，不跳复杂详情。                             |

## 6.5 退休目标

**•** 主视觉使用“退休小猪”场景，如小猪坐在椅子上、旁边有灯和植物。

**•** 目标金额红色大号，旁边提供编辑入口。

**•** 进度展示可以使用进度条或圆环，但要轻量，不要像复杂理财仪表盘。

**•** 使用“慢慢攒息，稳步前行”一类文案，降低焦虑。

## 6.6 我的资产

| **卡片字段**   | **展示规范**                               |
|----------------|--------------------------------------------|
| 资产名称       | 左侧显示名称和代码，代码弱化。             |
| 今年已为我攒息 | 红色金额，优先级最高。                     |
| 下次预计到账   | 日期或“X天后”，辅助展示。                  |
| 我的平均股息率 | 用友好文案，不写“成本收益率”这类强专业词。 |
| 资产小猪       | 右侧展示该资产专属小猪，形成记忆点。       |

## 6.7 关注资产

| **卡片字段** | **展示规范**                                 |
|--------------|----------------------------------------------|
| 添加关注资产 | 顶部红色描边按钮，明确可添加。               |
| 当前股息率   | 当前机会状态，数字可用深色或红色弱强调。     |
| 目标股息率   | 用户设定目标，和当前股息率并列。             |
| 差距状态     | “还差0.6% / 已达到目标”，用浅红或浅绿标签。  |
| 关注小猪     | 小猪形象比我的资产更轻，表达“等待合适时机”。 |

# 7. 关键组件规范

| **组件**     | **用途**                    | **规范**                                             |
|--------------|-----------------------------|------------------------------------------------------|
| 红色金额     | 所有分红/已攒/待收/目标金额 | 字号大、留白足，不与涨跌混用。                       |
| 小猪主视觉卡 | 首页、弹窗、目标            | 插画不宜过大压迫内容，保持柔软呼吸感。               |
| 进度条       | 退休目标进度                | 细条或圆环，配合“已攒/目标/还差”。                   |
| 资产卡       | 我的资产/关注资产           | 左数据右小猪，避免表格化。                           |
| 状态标签     | 已到账/待到账/已达到目标    | 短词、圆角、浅底色。                                 |
| 底部导航     | 全局导航                    | 图标线性，选中使用安心绿或红色，建议资产页选中为绿。 |
| 弹窗         | 入账反馈                    | 大数字 + 小猪 + CTA，避免过多字段。                  |

# 8. 文案规范

| **不要说**    | **建议说**            | **原因**           |
|---------------|-----------------------|--------------------|
| 分红收益统计  | 今年已攒              | 更生活化。         |
| 预计分红日期  | 下一笔什么时候来      | 更像收钱。         |
| 成本股息率    | 我的平均股息率        | 降低专业感。       |
| 加入自选股    | 关注资产              | 比股票软件更温和。 |
| 触发买入条件  | 达到目标股息率        | 避免交易暗示。     |
| 持仓资产      | 我的资产 / 打钱小伙伴 | 增强陪伴感。       |
| 派息日/除权日 | 预计到账 / 已到账     | 更贴近用户心智。   |

# 9. 动效与反馈建议

**•** 新增到账时，小猪轻轻晃动，金币落入罐中，金额数字滚动到新值。

**•** 再次打开弹窗可有轻微彩屑，但时长控制在 0.8 秒以内，避免打扰。

**•** 退休目标进度变化时，进度条缓慢推进，配合“又近了一点”。

**•** 关注资产达到目标股息率时，只做轻提醒：“这只小猪达到你的关注目标了”。

**•** 账本新增记录可以出现浅红色短暂高亮，1.5 秒后恢复。
