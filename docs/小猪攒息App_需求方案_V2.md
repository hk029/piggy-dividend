**小猪攒息 App 需求方案**

一个把分红变成“攒进小猪罐”的被动收入陪伴型产品

版本：V2.0 \| 方向：A8布局 + A9清爽背景 + 小猪攒息资产体系 \| 日期：2026-07-01

# 1. 产品定位与设计结论

基于已确定的视觉方向，本产品不再以“股票分析”和“持仓盈亏”为主叙事，而是以“小猪存钱罐 + 攒息 + 退休目标”为核心心智。用户打开 App 的第一感受应是：钱在慢慢进来，小猪罐越来越满，距离退休目标又近了一点。

| **项目** | **结论**                                                                                                 |
|----------|----------------------------------------------------------------------------------------------------------|
| 产品名称 | 小猪攒息 / 攒息之旅，可在后续品牌阶段二选一。                                                            |
| 核心心智 | 每一笔分红都会落进小猪罐，慢慢攒出被动收入。                                                             |
| 视觉基准 | 采用 A8 的页面布局与小猪陪伴感，结合 A9 的干净背景与舒适留白，并保留 A11 的“我的资产/关注资产”信息结构。 |
| 关键差异 | 不是股票 App，而是一个“攒息存钱罐”。股票只是底层资产，前台表达是入账、账本、日历、目标和小猪资产。       |
| 默认策略 | 默认隐藏总资产与涨跌；分红、已到账、待入账、目标进度是核心信息。                                         |

| **一句话定义：**小猪攒息是一个帮助长期收息用户记录已到账分红、等待未来分红、追踪退休目标，并用小猪存钱罐建立正反馈的低刺激投资陪伴工具。 |
|------------------------------------------------------------------------------------------------------------------------------------------|

# 2. 用户目标与产品原则

| **用户目标**           | **产品回应**                                                     | **设计原则**                         |
|------------------------|------------------------------------------------------------------|--------------------------------------|
| 想感受到钱在进来       | 首页、弹窗、账本都优先展示“已攒/到账”金额                        | 已到账优先于预计；收钱感优先于分析感 |
| 想减少看股价焦虑       | 隐藏总资产、涨跌、K线等强波动信息                                | 低刺激，不把用户拉回交易心态         |
| 想知道下一笔什么时候来 | 攒息日历与首页下一笔到账倒计时                                   | 等待感、期待感要明确                 |
| 想为退休做长期目标     | 退休目标页展示目标金额、已攒、还差、预计年限                     | 长期主义可视化                       |
| 想管理已买和想买资产   | 资产页区分“我的资产”和“关注资产”                                 | 拥有和关注分离，避免混淆             |
| 想用股息率判断买入机会 | 关注资产展示当前股息率和目标股息率；我的资产展示买入时平均股息率 | 专业指标生活化表达                   |

# 3. 信息架构

| **一级入口** | **页面定位** | **核心内容**                                                               |
|--------------|--------------|----------------------------------------------------------------------------|
| 首页         | 小猪罐总览   | 今年已攒、退休目标进度、距离目标还差、本月累计分红、分红笔数、下一笔到账。 |
| 账本         | 分红入账流水 | 已到账、待到账、按月汇总、分红来源、到账状态。                             |
| 日历         | 攒息日历     | 按日期显示已到账和待到账分红，本月已收、本月待收、近期待到账。             |
| 目标         | 退休目标     | 目标金额、已攒金额、还差金额、预计达成年限、阶段里程碑。                   |
| 资产         | 资产管理     | 我的资产、关注资产、添加资产、添加关注资产、平均股息率/目标股息率。        |
| 我的         | 设置与隐私   | 隐私模式、金额显示、红色分红规则、数据口径、提醒偏好。                     |

# 4. 核心指标与口径

| **指标**         | **定义**                                      | **展示位置**     | **备注**                         |
|------------------|-----------------------------------------------|------------------|----------------------------------|
| 今年已攒         | 今年已到账分红金额合计。                      | 首页、目标、账本 | 最核心爽感数字，红色展示。       |
| 本月累计分红     | 当月已到账分红金额合计。                      | 首页、弹窗、账本 | 用于阶段反馈。                   |
| 待入账           | 已知或预测的未来分红合计。                    | 首页、弹窗、日历 | 需标注“预计”。                   |
| 退休目标进度     | 已攒金额 / 退休目标金额。                     | 首页、目标       | 可按已到账分红累计，不用总资产。 |
| 距离退休目标还差 | 退休目标金额 - 已攒金额。                     | 首页、目标       | 强调还差多少，不展示投资本金。   |
| 我的平均股息率   | 我持有该资产的预计年分红 / 我的平均买入成本。 | 我的资产         | 用户购买后的个人成本收益口径。   |
| 当前股息率       | 当前预计年分红 / 当前股价。                   | 关注资产         | 用于关注资产是否接近目标。       |
| 目标股息率       | 用户设定的理想买入股息率。                    | 关注资产         | 达到目标时可提醒。               |

# 5. 核心页面需求

## 5.1 首页：小猪罐总览

| **模块**   | **内容**                            | **交互/规则**                        |
|------------|-------------------------------------|--------------------------------------|
| 顶部欢迎区 | 小猪攒息、通知入口、隐私状态        | 不展示大盘、涨跌、总资产。           |
| 小猪英雄区 | 今年已攒 ¥8,426.50 + 小猪存钱罐插画 | 数字红色；小猪可随攒息进度轻微变化。 |
| 退休目标卡 | 目标进度、已攒、目标、还差金额      | 点击进入退休目标页。                 |
| 本月摘要   | 本月累计分红、分红笔数              | 点击进入账本筛选本月。               |
| 下一笔到账 | 预计日期、来源、金额                | 点击进入日历对应日期。               |
| 底部文案   | “每一笔分红，都是走向自由的一小步”  | 营造陪伴感。                         |

## 5.2 再次打开弹窗

| **项目** | **规则**                                                                                |
|----------|-----------------------------------------------------------------------------------------|
| 触发条件 | 用户上次打开至本次打开期间，存在 1 笔及以上新增“已到账”分红；或用户有待查看的到账记录。 |
| 展示内容 | “欢迎回来！最近有 N 笔分红到账”、本次新增金额、本月累计已攒、还有多少在路上。           |
| 主按钮   | 去看看小猪罐 / 查看账本，进入账本并高亮新增记录。                                       |
| 次操作   | 下次再看 / 我知道了。关闭后本次不再重复弹出。                                           |
| 节制规则 | 每日最多展示 1 次；金额为 0 时不展示；敏感金额隐藏模式下可显示为“+¥\*\*\*\*”。          |

## 5.3 分红账本

**•** 按“全部 / 已到账 / 待到账”切换，默认进入最近月份。

**•** 顶部展示本月已收金额、已收笔数；金额统一红色。

**•** 每条记录展示资产名称、到账/预计日期、状态、金额。

**•** 新增到账记录可短暂高亮，并支持通过弹窗跳转定位。

**•** 待到账记录必须展示“预计”标签，避免与已到账混淆。

## 5.4 攒息日历

| **模块**   | **需求**                                               |
|------------|--------------------------------------------------------|
| 月历区     | 用红色圆点/小红包/¥ 标记分红日期；区分已到账和待到账。 |
| 月度汇总   | 展示“本月已收到”和“本月还会收到”两张卡。               |
| 近期待到账 | 列出未来 7-30 天内预计到账记录。                       |
| 日期详情   | 点击日期显示当天分红来源、金额、状态。                 |
| 状态规则   | 已到账为实心红，待到账为浅红/描边，普通日期不抢眼。    |

## 5.5 退休目标

| **模块** | **内容**                                                       |
|----------|----------------------------------------------------------------|
| 目标设置 | 用户设置退休目标金额，默认可建议 50 万、100 万、300 万等档位。 |
| 目标进度 | 显示目标金额、已攒金额、还差金额、完成百分比。                 |
| 预计达成 | 基于近 12 个月已到账分红或用户自定义月均攒息估算年限。         |
| 情绪表达 | 小猪在退休场景中休息，强化“长期陪伴、慢慢变自由”。             |
| 编辑入口 | 目标金额、预计增速、计算方式可修改。                           |

## 5.6 资产：我的资产与关注资产

| **页面** | **对象**                 | **核心字段**                                               | **关键操作**                                             |
|----------|--------------------------|------------------------------------------------------------|----------------------------------------------------------|
| 我的资产 | 已买入并录入持仓的资产   | 今年已为我攒息、下次预计到账、我的平均股息率、特殊小猪形象 | 新增持仓、编辑成本/股数、查看到账记录、转为关注/取消。   |
| 关注资产 | 尚未买入或只想观察的资产 | 当前股息率、目标股息率、距离目标差距、是否已达到目标       | 添加关注、设置目标股息率、达到提醒、一键录入为我的资产。 |

# 6. 添加与编辑流程

| **流程**     | **步骤**                                                                | **结果**                                       |
|--------------|-------------------------------------------------------------------------|------------------------------------------------|
| 添加我的资产 | 搜索资产 -\> 填写买入成本/股数/日期 -\> 选择小猪形象或自动匹配 -\> 保存 | 生成我的平均股息率、预计分红、下次到账。       |
| 添加关注资产 | 搜索资产 -\> 设置目标股息率 -\> 选择提醒方式 -\> 保存                   | 进入关注资产列表，可追踪当前股息率与目标差距。 |
| 关注转持有   | 在关注资产卡点击“已买入” -\> 填成本/股数 -\> 保存                       | 该资产从关注资产复制到我的资产，保留关注历史。 |
| 编辑退休目标 | 进入目标页 -\> 修改目标金额/估算方式 -\> 保存                           | 首页和目标页同步更新进度。                     |
| 确认到账     | 待到账记录到期后自动或手动确认到账                                      | 进入已到账账本，触发小猪罐增长反馈。           |

# 7. 数据与提醒规则

**•** 到账状态分为：已到账、待到账、预计中、需确认。MVP 可允许用户手动确认到账。

**•** 分红数据口径优先级：公告数据 \> 历史分红推算 \> 用户手动维护。所有预测需标注“预计”。

**•** 提醒类型：新增到账提醒、即将到账提醒、关注资产达到目标股息率提醒、退休目标里程碑提醒。

**•** 隐私模式默认开启：隐藏总资产、持仓市值、浮动盈亏；允许显示分红金额，因为这是产品主叙事。

**•** “当前股息率”可能依赖实时或延迟行情，需标注更新时间；MVP 可使用延迟数据。

# 9. 验收标准

**•** 首页第一屏不出现 K 线、总资产、总盈亏、涨跌幅等股票 App 强特征。

**•** 用户能在 3 分钟内添加一个“我的资产”，并看到我的平均股息率与预计分红。

**•** 用户能添加一个“关注资产”，设置目标股息率，并看到当前股息率与目标差距。

**•** 用户再次打开 App 时，如果期间有新增到账，能看到汇总弹窗。

**•** 攒息日历能清楚区分本月已收到和本月还会收到。

**•** 所有分红金额使用红色，所有预计信息均有“预计/待到账”提示。
